Additional architecture details:
\begin{itemize}
    \item \textbf{MLP}: One-hot encoding of input sequences, flattened to $n \times 26$ dimensions.
    \item \textbf{CNN1D}: Kernel sizes [3, 4, 5] (default) or [3, 4, 5, 6] (optimized); max pooling over sequence dimension.
    \item \textbf{Transformer}: 4 attention heads; GELU activation; learnable positional encodings; mean pooling with padding mask.
    \item \textbf{LSTM/BiLSTM/GRU}: Final hidden state used for classification.
    \item \textbf{BiLSTM-Transformer}: BiLSTM output projected to embedding dimension, then processed by Transformer encoder.
\end{itemize}

\subsection{Data Fractions}
\label{appendix:fractions}

To assess data efficiency, we train each model on the following fractions of the training set: $\{1\%, 10\%, 30\%, 50\%, 75\%, 100\%\}$. Subsampling is performed using stratified sampling to maintain class balance across all fractions.

\subsection{Hardware and Software}
\label{appendix:hardware}

All experiments were conducted on:
\begin{itemize}
    \item \textbf{GPU}: NVIDIA A100 (80GB HBM2e)
    \item \textbf{CPU Memory}: 128GB RAM
    \item \textbf{Software}: PyTorch 2.x, Transformers 4.x, XGBoost 2.x, PEFT 0.x
\end{itemize}

Training times vary from approximately 2 minutes (small models, 1\% data) to 6+ hours (Llama-8B, full data).
