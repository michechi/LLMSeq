# Data

Raw MIMIC-IV data is not included in this repository per the 
PhysioNet data use agreement. To reproduce, download MIMIC-IV v3.1 
from https://physionet.org/content/mimiciv/3.1/ and place the 
following files in data/raw/mimic-iv/:
- diagnoses_icd.csv
- admissions.csv
- patients.csv
- d_icd_diagnoses.csv
